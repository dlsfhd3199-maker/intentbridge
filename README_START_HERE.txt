IntentBridge Codex 개발 시작 방법

1. 이 ZIP 파일을 원하는 폴더에 압축 풉니다.
2. ChatGPT 데스크톱 앱에서 Codex를 엽니다.
3. Codex에서 이 폴더를 로컬 프로젝트로 엽니다.
4. CODEX_START_HERE.md 파일을 열어 "1차 프롬프트"를 그대로 붙여넣습니다.
5. Codex가 작업을 완료하면 실행 화면을 확인합니다.
6. 이상 없으면 2차 프롬프트, 3차 프롬프트 순서로 진행합니다.

중요:
- reference 폴더의 HTML은 디자인/제품 설명 참고자료입니다.
- 기존 HTML에 기능을 계속 덧붙이지 않습니다.
- 새 Next.js 프로젝트로 재구축합니다.
- 실제 GA4 / Meta / ChatGPT Ads API 테스트는 마지막에 진행합니다.
